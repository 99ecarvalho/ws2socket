================================================================================
                       ARCHITECTURE
================================================================================

The implementation maintains the original websockify structure in C:

  Python Module           →  C Module              →  File(s)
  ─────────────────────────────────────────────────────────
  websocket.py            →  websocket.h/c        →  RFC 6455 protocol
  websocketserver.py      →  server.h/c           →  HTTP/WS server
  websocketproxy.py       →  proxy.h/c            →  TCP proxying
  auth_plugins.py         →  config.h/c (frame)   →  Auth framework
  Logging                 →  logging.h/c          →  Logging system
  Utilities               →  utils.h/c            →  Socket, crypto, buffers
  __main__.py             →  ws2socket.c          →  Main entry point
