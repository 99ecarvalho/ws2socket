================================================================================
                      MODULE DESCRIPTIONS
================================================================================

1. LOGGING MODULE (logging.h/c)
   Purpose: Multi-target logging with configurable levels
   Features:
     - 5 log levels: DEBUG, INFO, WARN, ERROR, CRITICAL
     - 3 output targets: console, file, syslog
     - Thread-safe logging with mutex
     - Timestamp support
     - Configurable facility for syslog

2. WEBSOCKET MODULE (websocket.h/c)
   Purpose: RFC 6455 WebSocket protocol implementation
   Features:
     - WebSocket connection management
     - Handshake handling (client and server)
     - Frame encoding/decoding (stubs ready for implementation)
     - Masking/unmasking
     - Control frames (ping, pong, close)
     - Continuation frames for large messages
     - SSL/TLS support

3. SERVER MODULE (server.h/c)
   Purpose: HTTP server with WebSocket upgrade support
   Features:
     - HTTP request parsing (stubs)
     - WebSocket upgrade detection
     - SSL/TLS context management
     - Client connection handling
     - Request/response management
     - Configurable listen address/port
     - Connection statistics

4. PROXY MODULE (proxy.h/c)
   Purpose: Bidirectional TCP proxying
   Features:
     - WebSocket to TCP forwarding
     - Client management
     - Target server connection
     - Data buffering with circular buffers
     - Connection statistics (bytes sent/received)
     - Graceful shutdown
     - Configurable timeouts and buffer sizes

5. UTILS MODULE (utils.h/c)
   Purpose: 40+ utility functions for core operations
   Sub-modules:
     a) String Functions
        - Case-insensitive comparison
        - Safe string copy
        - Host:port parsing
        - String trimming
     
     b) Base64 Functions
        - Base64 encoding
        - Base64 decoding
     
     c) Cryptographic Functions
        - SHA1 hashing (RFC 6455 requirement)
        - Random byte generation
     
     d) Socket Functions
        - Socket creation and configuration
        - Connection management
        - Data send/receive
        - Socket options (timeout, nodelay, keepalive)
        - Address formatting
     
     e) Buffer Functions
        - Circular buffer management
        - Thread-safe read/write
        - Buffer status queries

6. CONFIG MODULE (config.h/c)
   Purpose: Configuration and command-line argument parsing
   Features:
     - Default configuration initialization
     - Command-line argument parsing
     - Configuration file support (stubs)
     - Configuration validation
     - Usage and version information
   Command-line Options:
     - --help, --version
     - --listen, --port
     - --target
     - --cert, --key (SSL support)
     - --verbose
     - --log-file
     - --daemon, --pid-file

7. APPLICATION MODULE (ws2socket.c)
   Purpose: Main application entry point
   Features:
     - Logging initialization
     - Configuration loading
     - Server setup and initialization
     - Client connection handling
     - Signal handling (SIGINT, SIGTERM)
     - Graceful shutdown
     - Daemonization support
     - PID file management
     - Proxy client lifecycle
